Step 3: Choose Seating Layout

Select how the system should arrange students in the exam halls:

1. Alternate / Interleaved (Anti-Copying)

Places students from different departments next to each other on the same bench.

Example:
Bench 1 : [ BCA-1 ]  |  [ BCOM-1 ]
Bench 2 : [ BCA-2 ]  |  [ BCOM-2 ]

2. Sequential (Roll No. Wise)

Fills seats continuously based on register numbers, regardless of the department.

Example:
Bench 1 : [ BCA-1 ]  |  [ BCA-2 ]
Bench 2 : [ BCA-3 ]  |  [ BCA-4 ]

3. Department-wise Blocks

Allocates specific columns or halves of the room entirely to one department.

Example:
Left Row Benches : [ All BCA Students ]
Right Row Benches : [ All BCOM Students ]

4. Randomized Shuffle

Completely shuffles students randomly across all available seats.

Example:
Bench 1 : [ BCA-12 ]  |  [ BCOM-5 ]
Bench 2 : [ BCA-3 ]   |  [ BBA-8 ]
